ierisFX configuration file documentation

Minimum Configuration:

Key Description Possible Values
title The title of the application String
icon The icon of the application String
mainView The first view the application will show upon launch String
resizable If the application window is resizable Boolean

With the default configuration, the application will have a configuration equivalent to the following: 

    
[ierisfx]
title = ierisFx Application
main_view = main
icon_path = ""
resizable = false

This is the configuration that ierisFX treats specially, any further configuration should be placed in the configuration file is completely extensible and custom. Additionally, the configuration file can contain an additional section called [ierisfx.extras] that will be used to configure the ierisFX application further.
