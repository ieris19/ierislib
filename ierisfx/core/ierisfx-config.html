ierisFX configuration file documentation

Minimum Configuration:

Key Description Possible Values
title The title of the application String
mainView The first view the application will show upon launch String
resizable Deprecated since 3.2.3, next breaking version 4.0.0 will remove this key. Use the ierisfx.extras.resizable key instead. DEPRECATED
icon Deprecated since 3.2.3, next breaking version 4.0.0 will remove this key. Use the ierisfx.extras.resizable key instead. DEPRECATED

WARNING: Since version 3.2.3, the default values for the above properties have been deprecated. The configuration file will still work with the deprecated values, but ierisFx will log a warning message to the console. The next breaking version 4.0.0 will remove the deprecated default values permanently. Upon release of 4.0.0, this documentation will be updated to the new format and this notice will be removed, along with the deprecation warnings.

This is the minimum configuration that ierisFX requires to function, any further configuration should be placed in the configuration file is completely extensible and custom. Additionally, the configuration file can contain an additional section called [ierisfx.extras] that will be used to configure the ierisFX application further.

Supporting documentation

Color Type

ieriFX configuration defines Colors using the `javafx.scene.paint.Color` class. More specifically, the color is parsed using `Color#web(String)`. For ease of use, the following is an extract of the documentation. More information here

  • Any standard HTML color name
  • An HTML long or short format hex string with an optional hex alpha channel. Hexadecimal values may be preceded by either "0x" or "#" and can either be 2 digits in the range 00 to 0xFF or a single digit in the range 0 to F.
  • An rgb(r,g,b) or rgba(r,g,b,a) format string. Each of the r, g, or b values can be an integer from 0 to 255 or a floating point percentage value from 0.0 to 100.0 followed by the percent (%) character. The alpha component, if present, is a floating point value from 0.0 to 1.0. Spaces are allowed before or after the numbers and between the percentage number and its percent sign (%).
  • An hsl(h,s,l) or hsla(h,s,l,a) format string. The h value is a floating point number from 0.0 to 360.0 representing the hue angle on a color wheel in degrees with 0.0 or 360.0 representing red, 120.0 representing green, and 240.0 representing blue. The s value is the saturation of the desired color represented as a floating point percentage from gray (0.0) to the fully saturated color (100.0) and the l value is the desired lightness or brightness of the desired color represented as a floating point percentage from black (0.0) to the full brightness of the color (100.0). The alpha component, if present, is a floating point value from 0.0 to 1.0. Spaces are allowed before or after the numbers and between the percentage number and its percent sign (%).
